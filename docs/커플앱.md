## 업데이트 & 피드백 가이드

### 1단계 — 지금 바로 (Expo Go)
1. 폰에 **Expo Go** 설치 (iOS/Android)
2. PC에서 `npx expo start --tunnel`
3. 친구가 QR 스캔 → 바로 실행. 코드 저장하면 즉시 반영(Fast Refresh)
- 단점: 내 PC가 켜져 있어야 함

### 2단계 — 언제든 열어보게 (EAS Update)
1. `npx eas-cli@latest login` → `npx eas-cli@latest init`
2. 개발 빌드 한 번 만들어 친구 폰에 설치: `npx eas-cli@latest build --profile development`
3. 이후엔 JS 변경만 올리면 됨: `npx eas-cli@latest update --branch preview --message "변경 내용"`
- 친구는 앱을 다시 열기만 하면 새 버전 적용
- 네이티브 모듈을 추가했을 때만 다시 빌드 필요

- 반영 내용은 [[#업데이트 로그]]에 기록

## 기술 결정

### 백엔드 — Supabase (적용됨)
- 프로젝트: `https://lsjtoaikseiichahpqzi.supabase.co` (Seoul)
- 앱 설정: `.env`의 `EXPO_PUBLIC_SUPABASE_URL`, `EXPO_PUBLIC_SUPABASE_KEY` (publishable 키 — 공개돼도 됨)
- **secret / service_role 키는 절대 앱·저장소·채팅에 넣지 말 것**
- 화면은 `useCouple()`만 사용 → 서버 연동은 `src/store/couple-store.tsx`에만 있음
- 상대가 바꾼 데이터는 Realtime으로 해당 테이블만 다시 불러옴
- 스키마 변경은 `supabase/migrations/`에 새 파일(0002_...)로 추가하고 SQL Editor에서 실행
- 권한: "Automatically expose new tables" 꺼둠 → 새 테이블은 SQL에서 직접 GRANT + RLS 정책 작성

#### 처음 한 번 세팅
1. SQL Editor → `supabase/migrations/0001_init.sql` 전체 붙여넣고 Run
2. Authentication → Sign In / Providers → Email → **Confirm email 끄기** (둘만 쓰는 앱이라 메일 인증 생략)

### 사진 앨범 용량
- 기기 메모리가 아니라 클라우드 스토리지에 저장 → 폰 용량 문제 없음
- 업로드 전 리사이즈/압축, 목록은 썸네일만 로드
- 비용 포인트는 스토리지 용량 (Supabase 무료 1GB). 업로드 품질 0.7로 압축 중

### 음악 연동
- 브라키 셋리스트: 공개 API 없음 → 링크 저장 방식
- **YouTube Music "지금 듣는 노래": 공식 API 없음 → 불가**
- Spotify는 Web API(currently-playing)로 가능 — 원하면 대안
- 현재: 오노추 수동 입력 + 링크

### 지도
- `react-native-maps`(개발 빌드 필요) 또는 세계지도 SVG에 방문 국가 색칠

### 비밀연애 모드

## 디자인 적용 가이드

**결론: 나중에 Figma/CSS로 디자인 입히는 것 가능.** 기능 먼저 만들고 디자인은 나중에 씌우는 구조로 되어 있음.

### 구조
- 색·간격·모서리·폰트: `src/theme/tokens.ts` 한 곳 → 여기만 바꾸면 전체 반영
- 공통 부품: `src/components/ui/` (Button, Card, Chip, TextField, Screen) → 부품만 바꾸면 모든 화면 반영
- 현재 들어간 핑크 톤/이모지/둥근 카드는 **임시**

### CSS 관련 주의
- React Native는 브라우저 CSS가 아니라 `StyleSheet`(CSS와 거의 같은 문법, camelCase) 사용
- Figma Dev Mode의 CSS 값을 그대로 옮기면 됨 (`border-radius: 16px` → `borderRadius: 16`)
- Tailwind 문법이 편하면 NativeWind 도입 가능

### Figma → 앱 흐름
1. Figma에서 색/폰트/간격을 Variables(또는 Tokens Studio)로 정리
2. 값을 `tokens.ts`로 옮기기
3. 아이콘/캐릭터는 SVG·PNG(또는 Lottie 애니메이션)로 내보내 `assets/`에 추가
4. Figma 링크나 스크린샷을 주면 Claude가 컴포넌트에 반영 가능
