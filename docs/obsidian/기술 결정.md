# 기술 결정

## 백엔드 — Supabase 추천 (미적용)
- 로그인, Postgres DB, 실시간(채팅), 파일 스토리지(사진·손편지)를 한 번에 해결. 무료 티어로 충분
- 화면은 `useCouple()`만 쓰므로 `src/store/couple-store.tsx`의 액션만 Supabase 호출로 바꾸면 됨
- **나만 보는 메모**는 RLS(행 단위 권한)로 작성자 본인만 읽게 해야 진짜 비밀이 됨
- **편지 "열기 전 내용 숨김"**도 서버에서 opened 전에는 body를 안 내려주는 게 안전

## 사진 앨범 용량
- 기기 메모리가 아니라 클라우드 스토리지에 저장 → 폰 용량 문제 없음
- 업로드 전 리사이즈/압축, 목록은 썸네일만 로드
- 비용 포인트는 스토리지 용량 (Supabase 무료 1GB)

## 음악 연동
- 브라키 셋리스트: 공개 API 없음 → 링크 저장 방식
- **YouTube Music "지금 듣는 노래": 공식 API 없음 → 불가**
- Spotify는 Web API(currently-playing)로 가능 — 원하면 대안
- 현재: 오노추 수동 입력 + 링크

## 지도
- `react-native-maps`(개발 빌드 필요) 또는 세계지도 SVG에 방문 국가 색칠

## 비밀연애 모드
- 알림 발송 규칙은 `src/lib/notifications.ts`의 `shouldNotify()` 한 곳에서 관리
