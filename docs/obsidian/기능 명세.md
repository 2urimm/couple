# 기능 명세

| 기능 | 파일 | 상태 |
|---|---|---|
| D-Day (사귄 날 1일 기준, 다음 100일 단위) | `src/app/(tabs)/index.tsx`, `src/lib/date.ts` | 뼈대 완료 |
| 채팅 | `src/app/(tabs)/chat.tsx` | 로컬만 |
| 비밀연애 모드 — 켜면 채팅 알림 X | `src/app/settings.tsx`, `src/lib/notifications.ts` | 규칙만 |
| 캐릭터 예뻐해주기 / 예뻐해주세요 요청 / 하트 던지기 | `src/app/character.tsx` | 뼈대 완료 |
| 궁금한 거 질문 — 내가 답해야 상대 답 보임 | `src/app/questions.tsx` | 뼈대 완료 |
| 같이 하고 싶은 것 (먹는 거/노는 거/가는 거) | `src/app/bucket-list.tsx` | 뼈대 완료 |
| 가본 지역·국가 + 즐겨찾기 | `src/app/places.tsx` | 지도 미구현 |
| 편지 — 날짜별 보관, 열기 전 내용 숨김, 손편지 스캔 업로드 | `src/app/letters.tsx` | 뼈대 완료 |
| 사진 앨범 — 캘린더 날짜 연동 | `src/app/album.tsx` | 로컬만 |
| 오늘의 노래(오노추) | `src/app/music.tsx` | 수동 입력 |
| 캘린더 — 개인 일정 공유 / 데이트 후기 댓글 | `src/app/(tabs)/calendar.tsx` | 로컬만 |
| 나만 보는 메모 (상대 취향 기록) | `src/app/notes.tsx` | 로컬만 |

데이터 모델: `src/types/models.ts` / 상태: `src/store/couple-store.tsx`
