# 로컬 세팅 (Windows)

## 클론
```powershell
mkdir F:\Side_Project
cd F:\Side_Project
git clone https://github.com/2urimm/couple.git
cd couple
git checkout claude/sweet-lovelace-8ty3yr
npm install
npx expo start
```

## 이 노트를 Obsidian 볼트로
노트 원본은 저장소의 `docs/obsidian/`에 있음. 둘 중 하나:
- 복사: `docs\obsidian\*` → `F:\Obsidian\side-project\`
- 링크(추천 — 저장소와 자동 동기화, 관리자 권한 불필요):
  ```powershell
  New-Item -ItemType Directory -Force F:\Obsidian\side-project
  New-Item -ItemType Junction -Path F:\Obsidian\side-project\couple -Target F:\Side_Project\couple\docs\obsidian
  ```
  → 옵시디언에서 `side-project/couple` 폴더로 보임. 노트를 고치면 저장소 파일이 바로 바뀜
  → 동기화: 새 내용 받기 `git pull`, 내가 쓴 노트 올리기 `git add docs/obsidian; git commit -m "노트 업데이트"; git push`

## 필요한 것
- Node.js 20 이상 (LTS)
- 폰에 Expo Go
