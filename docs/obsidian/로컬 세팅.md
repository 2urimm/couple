# 로컬 세팅 (Windows)

## 클론
```powershell
mkdir F:\Side_Project
cd F:\Side_Project
git clone https://github.com/2urimm/couple.git
cd couple
git checkout claude/sweet-lovelace-8ty3yr
npm install
npx expo start
```

## 이 노트를 Obsidian 볼트로
노트 원본은 저장소의 `docs/obsidian/`에 있음. 둘 중 하나:
- 복사: `docs\obsidian\*` → `F:\Obsidian\side-project\`
- 링크(관리자 PowerShell, 저장소와 자동 동기화):
  `New-Item -ItemType Junction -Path F:\Obsidian\side-project\couple -Target F:\Side_Project\couple\docs\obsidian`

## 필요한 것
- Node.js 20 이상 (LTS)
- 폰에 Expo Go
