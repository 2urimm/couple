# 디자인 적용 가이드

**결론: 나중에 Figma/CSS로 디자인 입히는 것 가능.** 기능 먼저 만들고 디자인은 나중에 씌우는 구조로 되어 있음.

## 구조
- 색·간격·모서리·폰트: `src/theme/tokens.ts` 한 곳 → 여기만 바꾸면 전체 반영
- 공통 부품: `src/components/ui/` (Button, Card, Chip, TextField, Screen) → 부품만 바꾸면 모든 화면 반영
- 현재 들어간 핑크 톤/이모지/둥근 카드는 **임시**

## CSS 관련 주의
- React Native는 브라우저 CSS가 아니라 `StyleSheet`(CSS와 거의 같은 문법, camelCase) 사용
- Figma Dev Mode의 CSS 값을 그대로 옮기면 됨 (`border-radius: 16px` → `borderRadius: 16`)
- Tailwind 문법이 편하면 NativeWind 도입 가능

## Figma → 앱 흐름
1. Figma에서 색/폰트/간격을 Variables(또는 Tokens Studio)로 정리
2. 값을 `tokens.ts`로 옮기기
3. 아이콘/캐릭터는 SVG·PNG(또는 Lottie 애니메이션)로 내보내 `assets/`에 추가
4. Figma 링크나 스크린샷을 주면 Claude가 컴포넌트에 반영 가능
